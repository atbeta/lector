# v1 验收记录

状态（2026-09-18）：自动门全部通过；**成功标准 1 / 2 / 4 需要在一台有 GUI 的机器上人工实测**，
本文给出可复现的步骤与记录表。其余三条有自动化或结构性保证。

## 怎么跑（自动门）

```
bun test                      # 362 pass，含 core 保真与 text-integrity
bun run typecheck             # tsc --noEmit
cargo test --lib              # 20 pass，壳侧几何 / 协议白名单 / 原子写
bun run verify:ui             # ui-verify + refactor-verify + block-indicator-verify
node tools/design-audit.mjs   # 版式/对比度，0 error 0 warn
```

`verify:ui` 没浏览器时会打印 SKIP 并以 0 退出；想当失败用 `--strict`。
本机一次运行中的浏览器侧参考值：大文件（约 2MB / 5 万行）从导航到可编辑 **141ms**、
`mode=source`、整篇裸 CM、DOM 只渲染 56 行（视口虚拟化生效）。

## 人工验收 A：打开与冷启动（成功标准 1 / 2）

前置：用 **release 包**（安装器或便携版），不是 `tauri:dev`。

1. 冷启动：完全退出应用 → 双击任意普通 md（少量图）→ 秒表/手机慢动作量「双击到正文出现」。
   冷启动若 > 1.5s，按 01-brief 的兜底：先出纯文本再切 IR（目前未实现）。
2. 热打开：应用已开着 → 双击**另一篇** md → 量「双击到正文出现」，目标 < 300ms。
3. 辅助证据：release 日志在 `%APPDATA%\com.lector.reader\logs\`，`[win]` 行给出建窗起止时间
   （机器可读的窗口创建下限，不含双击到壳收到路径的那段）。

## 人工验收 B：中文 IME（成功标准 4）

在**编辑档**的段落里，用系统输入法逐条试：

1. 段落**中间**插入中文长句（不只在段尾），不丢字、光标不跳。
2. 候选窗跟随光标；翻页选词正常。
3. 中英混输、数字与标点混输。
4. 段落最后连续输入长句后停顿，再继续输入，已输入内容不回退、不重复。
5. 退出编辑（Esc / 点别块）后再进来，内容与磁盘写回一致。
