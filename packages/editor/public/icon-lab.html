Key Issues in Current Version (0bf49dd):

1. App Icon: The heavy dark plate houses a cramped, thick "L" constricting a squished "M". The lone red ribbon drooping from the top edge looks like unremoved packing tape rather than an intentional bookmark. It lacks the airy, typographic elegance expected of a "reading-first" Markdown editor.
2. Document Icon: Slapping a dark, heavy app plate onto the bottom-left corner creates a jarring visual imbalance and turns into an illegible muddy blob at 32px / 16px in File Explorer and Finder.
