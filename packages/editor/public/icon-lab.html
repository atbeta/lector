Key Issues Identified in Current Version (0bf49dd):
1. App Icon: Suffocating Cage & Red Tape
Thick serif "L" constricts a squished "M" with zero breathing room. The drooping red tape looks like unremoved packing tape and blurs into a colored artifact at 32px / 48px.
2. Document Icon: Clunky Left-Bottom Weight
Slapping a solid black app block on the bottom-left corner heavily unbalances the paper sheet. In Finder / File Explorer it looks like an accidental blotch.
